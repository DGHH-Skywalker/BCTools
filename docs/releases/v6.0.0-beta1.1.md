# BCTools 6.0.0-beta1.1

此 Windows x64 预发行版修复 Excel 导入的数据完整性问题，并支持在主程序中直接解密酷狗歌曲。应用版本为 `6.0.0-beta1.1`，便携版与安装包的 Windows 数字文件版本为 `5.10.0.2`。

## Excel 导入

- 批量导入时，每首歌曲在仓库写入期间分配独立 ID。普通新增歌曲使用相同的分配规则，因此并发新增与导入也能各自获得唯一 ID。
- 导入覆盖歌单前，先保存与本次替换对应的快照。若备份失败，导入立即取消并提示错误，原歌单保留。
- 每次导入使用独立的快照文件名。连续导入时可以分别恢复各次覆盖前的歌单。

## 酷狗自动解密

- 主程序的歌曲导入支持 KGG、KGM、KGMA 和 VPR。选择文件后由后端解密，可以直接入库。
- Windows 启动时会从常见酷狗目录与注册表记录的安装位置查找 `KGMusicV3.db`。也可在「设置 → 软件信息 → 酷狗自动解密」指定数据库。
- 验证通过的数据库副本保存在 `BctoolData/kugou`。启动时检查版本变化。源文件缺失时静默使用上一次可用副本。um-react 可从同一份本机副本按歌曲取钥。

## um-react 回传

- 解密完成后显示「导入」按钮。回传复用主程序的导入页，入库确认后清除对应的解密卡片。
- 修复部分短音频或截断文件导致音频识别一直转圈的问题。
