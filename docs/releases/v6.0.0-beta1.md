# BCTools 6.0.0-beta1

这个 Windows x64 预发行版加入 Wails 桌面模式、自动清理和可切换的插件布局。应用显示版本为 `6.0.0-beta1`，便携 EXE 与安装程序的 Windows 数字文件版本均为 `5.10.0.1`。

## 两种启动方式

- 双击 `bctools.exe` 仍会打开默认浏览器，原有的托盘入口继续可用。
- 在命令行执行 `bctools.exe desktop` 可直接打开桌面窗口。桌面模式使用 Wails v3 和 Microsoft Edge WebView2 Runtime，支持独立的设置、音乐解锁与导入窗口，以及原生文件保存对话框。
- 两种模式共用 `BctoolData` 和同一个 Go 后端。桌面模式通过进程内 `http.Handler` 加载应用和接口，同时独立提供 `1743` 端口供局域网访问。端口被占用时，桌面窗口仍可提供本机功能。
- 同一数据目录由单个后端实例持有。从已运行的浏览器模式进入桌面模式时，会请求原后端正常退出，再接管数据目录。重复打开桌面模式会唤回现有窗口。

## 音频与歌单数据

- 默认保留当前及前三个 ISO 周的歌曲音频，保留过去两年的歌曲信息及未来排期。可在设置页调整保留期、手动清理或查看可恢复的清理批次。
- `MusicFiles/<周>/songs.json` 保存有音频的歌曲信息，无对应音频的记录合并到 `songs-without-audio.json`。
- 清理先将过期内容移入七天回收区。旧布局自动迁移，并保留七天的旧版 `data.json` 备份。写入中断后可在下次启动时重放文件事务。
- 合并音频中的单曲可直接按区间试听和定位。改进了上传失败时的临时文件清理与快照恢复的路径校验。

升级前建议退出旧版并完整备份 `BctoolData`。如需降级，请退出 Beta，再把升级前的整个目录恢复到旧版对应位置。旧版读取单体 `data.json`，Beta 使用拆分后的数据布局。

## 插件、接口与热更新

- 设置页支持安装、启用、停用和卸载插件。插件可替换首页和导航，添加菜单、页面和 WASM 命令。内置示例可直接体验布局切换，歌单、播音和导出等业务模块继续由内置实现提供。
- 新增 `/api/v1` 及 `/api/v1/openapi.json`，提供 49 个路径与 57 个操作的契约，并生成 Go 和 TypeScript 类型。原有 `/api` 路由仍可使用。
- 新增 TUF 签名更新，覆盖公告、模板、配置、插件、主界面、音乐解锁资源及 Windows 程序。客户端校验签名和文件完整性，镜像故障时尝试其他来源。当前 Beta 的生产更新仓库与信任根仍待配置，升级请使用 GitHub Release 下载的安装包或便携版。[签名更新文档](https://github.com/DGHH-Skywalker/BCTools/blob/v6.0.0-beta1/docs/SIGNED_UPDATES.md)
