# BCTools 5.8.0.0

本版本集中改善设置操作、歌曲时段调整、播音歌单响应和 Windows 安装体验，并完成更新日志信任链与构建流程的现代化改造。

## 用户体验

- 设置中心改为独立页面，不再显示软件主侧边栏；设置专属侧边栏顶部提供“返回主界面”。
- 从主界面进入软件设置时，会复用并聚焦已经打开的设置窗口；不存在时才新建窗口。
- 移除使用指南中的重复返回按钮。
- “导出偏好”更名为“歌单背景设置”，并从抽屉改为页面内设置；沿用既有存储键并同步旧版字段，升级或回退版本时可继承背景配置。
- “宿舍时段与查重”更名为“时间配置”。
- 设置侧边栏展开时显示完整“返回主界面”按钮，收缩时保留可点击的返回图标。
- 播音栏目页面改为紧凑的响应式多列布局，保留原有 `broadcastColumnMap` 字段和后端存储格式。
- 调整时间段时，原时间段的歌曲会优先继承到新时间，未修改时间段的歌曲保持原有分配。
- 优化播音歌单添加歌曲时的查重与异步处理，降低歌曲较多时的等待时间。

## 安全更新日志

- 后端可从 `BctoolData/update-log.json` 和 `BctoolData/update-log.sig` 读取外部更新日志。
- 外部 JSON 必须通过 Ed25519 签名验证，并通过 schema、版本、发布时间、有效期、正文长度和 HTTPS 下载地址校验。
- 私钥保存在仓库外的受限发布位置，不会进入应用或仓库，后端仅嵌入公钥；文件缺失、损坏、过期或被篡改时会静默回退到可执行文件内置日志。
- 外部日志不得早于内置版本或发布时间，有效期最长 90 天，以降低旧签名日志被回放的风险。
- 前端只展示后端已经验证的结果，不参与信任判断。
- 发布后 14 天内由后端原子分配一次展示机会；同一次启动下的多个页面、窗口或标签不会重复弹出。
- 提供 `GoServer/cmd/sign-update-log` 离线签名工具，详细操作见 `docs/UPDATE_LOG.md`。

## Windows 安装程序

- 默认构建已从自定义 C++/Win32 安装器迁移到 Inno Setup 6，产物名称保持为 `BCTools-Setup.exe`。
- 安装界面使用经过人工校订的简体中文文本，并保留当前用户/所有用户安装模式选择。
- 稳定的 Inno `AppId` 用于识别首次安装、升级和重装；同版本再次运行可用于修复安装。
- 桌面和开始菜单快捷方式使用固定路径，升级或重装时覆盖更新，不会重复创建。
- 更新或卸载前通过现有 `/api/shutdown` 接口请求 BCTools 安全退出，进程未退出时不会替换应用文件。
- 当前用户模式默认安装到 `%LOCALAPPDATA%\Programs\BCTools`，所有用户模式默认安装到 `%ProgramFiles%\BCTools`；用户数据位于相应安装目录下的 `BctoolData`。
- 升级和普通卸载默认保留用户数据；交互卸载可明确选择删除，静默卸载仅在传入 `/REMOVEUSERDATA` 时删除。
- 支持图形安装、升级、重装、静默安装和静默卸载，兼容包含空格及非 ASCII 字符的路径。

## 构建与版本

- 版本号统一更新为 `5.8.0.0`，覆盖 Go 版本常量、Windows 文件版本资源、前端包和旧安装器兼容头文件。
- 根构建入口统一为 `npm run build`：并行构建 Vue、React 和 FFmpeg 资源，随后生成 Go 可执行文件并调用 Inno Setup。
- GitHub Actions 默认构建与 Release 工作流均改用 Inno Setup，发布时上传 `bctools.exe`、`BCTools-Setup.exe` 和 `SHA256SUMS.txt`。
- 旧 C++ 安装器源码暂时保留用于行为对照，但不再进入默认构建流程。

## 验证范围

- 自动测试覆盖有效/无效签名、缺失文件、损坏 JSON、过期日志、内置回退及 14 天展示规则。
- 已完成前端 37 项测试、全部 Go 测试、Vue 类型检查和 Go vet。
- 已验证首次安装、实际启动、桌面与开始菜单快捷方式、5.7 到 5.8 升级、同版本重装、运行中升级与卸载、用户数据保留/显式删除、静默安装/卸载及快捷方式不重复。
- 本地产物已在包含空格和中文字符的路径中验证。

```powershell
& .\BCTools-Setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /CURRENTUSER
& "$env:LOCALAPPDATA\Programs\BCTools\unins000.exe" /VERYSILENT /SUPPRESSMSGBOXES /NORESTART
& "$env:LOCALAPPDATA\Programs\BCTools\unins000.exe" /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /REMOVEUSERDATA
```
