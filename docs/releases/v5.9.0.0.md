# 5.9.0.0

- 歌单、设置、快照及音频改用当前用户固定目录 `%LOCALAPPDATA%\BCTools\Data`，移动 EXE 后仍使用同一份数据。
- 首次复制迁移保留来源；发现不同歌单时选择来源。软件信息页可比对、选择补回旧目录的记录，导入前备份。
- 启动时发现并登记较新程序，旧启动器跳转到较新版受管副本；同版重复启动复用现有实例。
- 歌名自动保存，失败保留草稿；刷新后可核对恢复。安全版本切换等待页面确认、在途写入和后台任务落盘，再退出原实例。
- 时段改时间或排序保留 ID，删除设置和解除歌曲关联原子提交；历史播音时段缺失显示待确认。
- 播音导出保留此前的三列布局修复。

版本发现覆盖当前程序目录、受管/登记目录、默认安装目录、桌面、下载目录和登记的搜索目录，递归搜索有限。原始历史 EXE 没有新启动协议；首次升级应先保存旧页面并从托盘退出。失联页面或保存失败会阻止安全切换。
