# BCTools 6.0.0-beta1 迁移审查

审查以 `a146aedf0b0eed87fa502e982993ffa05df85215` 为基线。逐行对照了两种启动入口、路由注册和共享后端的初始化与退出，沿调用链复核了桌面窗口、文件导入、音频读取、数据迁移和更新落盘。另对 Go、Vue、um-react、构建脚本及安装配置进行了全树静态搜索，覆盖约 3.8 万行源文件和配置。旧模块按入口和搜索结果复核，未对全部旧代码逐行人工审计。

## 后续模块插件化边界

现有模块继续在同一 Go 进程内提供宿舍歌单、播音、导出和音频服务。第一阶段通过版本化 API 契约、插件权限和页面贡献隔开调用者与内部存储。`playlist.read` 当前只暴露歌单计数。首页、导航、插件页和命令已经可以在运行中切换。

下一阶段可把导出、音频处理和歌单操作分别定义为可替换的宿主能力，由内置实现提供默认行为。外部实现通过同一输入输出契约声明兼容版本和权限，宿主选择启用的提供者。写入歌曲、处理本地文件和创建原生窗口依然由宿主负责校验。这样插件可以逐步接管完整业务流程，同时由内置实现提供故障回退。
